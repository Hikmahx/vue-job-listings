## Notes

1. **Password**: All users use `Password123!` for testing purposes. In production, ensure passwords are properly hashed.

2. **Dates**: Use the exact date format shown (YYYY-MM-DD) for `dateOfBirth` and `postedAt` fields.

3. **Company IDs**: Replace `<company_id>` placeholders in job data with actual MongoDB ObjectIds after creating companies.

4. **User IDs**: Replace `<founder_user_id>` placeholders with actual MongoDB ObjectIds after creating users.

5. **Job Creation Order**: 
   - Create users first (job seekers, employees, founders)
   - Create companies (linked to founders)
   - Create CompanyMember records (linking founders to companies)
   - Create jobs (linked to companies)

6. **Logo Paths**: Logo paths are relative to your frontend public/images directory. Adjust as needed for your setup.

7. **Salary Ranges**: All salaries are in USD per year. Adjust currency and amounts as needed for your use case.

8. **Skills**: Skills are stored as arrays. Ensure your database schema supports array types.

9. **Job Details**: The `details` field contains nested objects. Ensure your schema supports nested documents or create separate JobDetails records.

10. **Posted Dates**: For `postedAt` in jobs, use actual Date objects. The "1d ago", "2w ago" format is for display only.
